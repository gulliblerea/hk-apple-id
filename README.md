## ⚠️ 使用铁律（所有外区账号通用）

**① 只登 App Store，不登 iCloud**
App Store → 右上角头像 → 拉到底 → 退出登录 → 输入账号。
**不要**在「设置」最顶部登录，那是 iCloud 入口，会带来激活锁风险。

**② 弹「升级账户安全」选「不升级」**
选「其他选项」→「不升级」。开了双重认证，其他人就用不了了。

**③ 下载完立刻退出**
不退出会占用账号、触发风控、被锁号——这是共享账号最常见的死法。
